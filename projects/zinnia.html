Zinnia All Day

Project Overview

Sponsored by Zinnia TV, this Winter Capstone project (Team Capybara G02) explores how caregivers can structure daily routines using dementia-friendly video content.

02 — Problem Context & Statement

The Problem

  • Caregivers experience stress, burnout, and cognitive overload
  • Behavioral symptoms worsen without routine
  • Technology often adds complexity instead of reducing it

Zinnia TV provides dementia-friendly content, but caregivers cannot:

  • Organize content by time of day
  • Customize schedules
  • Build playlists

Problem Statement

How might caregivers schedule daily content in a way that supports routine and reduces distress for both themselves and the person they care for?

03 — Research Insights

  • Evenings are the most challenging time
  • Caregivers want guided—not fully automated—control
  • Routines must remain flexible

Key Insight: “Caregiving requires fluidity and customizability.”

04 — Personas

Spouse Caregiver (Age 71)

Tech Comfort: Low

Needs: Reduce stress, maintain routine

Pain Points: Restlessness, constant decision-making

Remote Caregiver (Age 41)

Tech Comfort: High

Needs: Monitor and support from afar

Pain Points: Lack of visibility into daily routine

05 — Key Concepts & Validation

Structured Scheduling

Morning, afternoon, evening routines

Pre-planned Programming

Reduce decision fatigue

Engagement

Encourage shared interaction

Validation Findings:

  • Caregivers want structured routines
  • No comparable tools exist
  • Needs are highly specific

06 — Solution & Key Features

  • Drag-and-drop schedule builder
  • Time-of-day content blocks
  • Pre-built playlists for quick access
  • Simple 3-step flow: pick genre → select videos → build schedule
