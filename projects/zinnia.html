Project Overview

Sponsored by Zinnia TV, this project explores how caregivers can structure daily routines using dementia-friendly content.

TL;DR

Designed a scheduling system that reduces caregiver cognitive load by turning content selection into a structured daily routine.

Problem

Caregivers face constant decision fatigue and lack tools to structure daily routines effectively.

Research Insight

Caregivers want guidance—not automation—and need tools that support flexible routines.

Solution

A scheduling system that allows caregivers to plan content by time of day using a simple workflow.

Impact

  • Reduced caregiver decision fatigue
  • Improved consistency in daily routines
  • Introduced structured planning into content use
